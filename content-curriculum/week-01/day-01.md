# Day 1: 接続思考・概論・エンジニア革命・導入

## この日のゴール

接続思考とは何かを理解し、自分の現在の開発プロセスを「接続」の視点で
分析できるようになる。

## 午前: 導入・アイスブレイク・現状把握（10:00-12:15）

- β受講生の自己紹介と技術バックグラウンドの共有
- 個人の技術課題・チーム課題の洗い出し
- 接続思考・概論ビデオの視聴とディスカッション

### ワークショップ: 「個人脳の完結」とその限界

個人の中で完結する開発プロセスが、なぜスケールしないのかを体験する。

```js
// 個人最適化の典型: 自分しか読めない省略記法
const f = (d) =>
  d.map((x) => x?.v ?? 0)
    .reduce((a, b) => a + b, 0);
```

このコードは書いた本人には最速でも、チームには解読コストを押し付ける。
**個人の最適化 ≠ システムの最適化** — これが接続思考の出発点。

## 午後: 現状分析・診断・個別評価（14:00-15:00）

## 目標設定・学習計画（15:15-16:15）

- 学習計画の個別調整（強みの活用・弱みの補強）
- 週次進捗確認とフィードバックの方法説明
