# Day 2: 根拠の強度評価 — 弱い根拠に強い結論を支えさせない

## この日のゴール

Day 1 で仕分けた根拠に**強度**を持たせる。
根拠は「ある/ない」でなく「どれだけ強いか」で評価し、
弱い根拠の上に強い結論を建てないようにする。

## 根拠の強度の階層

事実と意見の間にも、確かさの段階がある。

```text
強い ─ 検証済みのデータ（自分の記録・再現済みの結果）
   │    検証可能な事実（誰でも確認できる）
   │    経験則・権威（「あの人もそう言っていた」）
   │    多数派（「みんなそうしている」）
弱い ─ 願望（「こうなってほしい」）
```

落とし穴は中段である。経験則、権威者の発言、「みんなそう言ってる」は、
専門分野では**事実の顔をしてしまう**。判断の前に、自分の根拠が
この階層のどこにいるかを一瞬問う習慣をつける。

## ワークショップ: 専門分野の「常識」分析

自分の専門分野で、「常識」とされているが実は**意見**であるものを
1つ特定する。

- 見つけ方: 「なぜそうするのか？」と2回連続で問う。
  答えが「昔からの慣習」「有識者の見解」「他社も同じ」に落ちたら、
  それは根拠ではなく経験則・権威・多数派である
- 注意: 区別を追求しすぎると「分析麻痺」で判断できなくなる。
  強度評価は判断前に一瞬使う道具であって、永久に分類し続ける
  作業ではない。全てを検証してから判断する必要はない
  （重要な判断ほど強度を厳しく見る、で十分である）

## 思考の階層 — 自分がどの層で判断したか

思考は5つの階層で分解できる。

| 階層 | 内容 |
| --- | --- |
| 表層 | 直感・第一印象 |
| 論理 | 因果関係・根拠の連結 |
| メタ | 自分の思考プロセスそのものの分析 |
| 価値 | 優先順位・何を大切にするか |
| システム | 全体の関係性・影響の連鎖 |

根拠の強度評価は主に「論理」の階層の作業である。
判断ログの `weight`（重視した基準）は「価値」の階層に属する —
Day 1 の仕分けと合わせて読むと、「事実だと思っていた根拠」が
実は自分の価値層から来ていたケースが見つかることがある。

## 品質5軸での自查

判断1件の質を、5つの軸で採点する（各軸5段階）。

| 軸 | 問い |
| --- | --- |
| 論理性 | 結論と根拠に矛盾・飛躍はないか |
| 網羅性 | 選択肢・視点・影響範囲を漏れていないか |
| 深度 | 本質に迫っているか、表面的でないか |
| 創造性 | 独自の視点があり、かつ実用か |
| 実行性 | 具体的に実行可能か |

採点の目的は得点化ではなく、**軸ごとの偏り**を見ることである。
例えば「実行性だけ高く網羅性が低い」なら、見ていない選択肢が
ある疑いがある。

## 成果物（Day 2終了時）

1. 判断ログの根拠を強度階層に配置した結果
2. 専門分野の「常識の顔をした意見」1件と、それを見抜いた問いの記録
3. 判断ログ1件の品質5軸自查と、最弱軸への対処案
