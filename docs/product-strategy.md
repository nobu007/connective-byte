# 商品戦略 — 売る単位を「情報」から「判定」へ

確定: 2026-09-04（nobu007）。カリキュラム課金の商品定義の正本。運用規律（CLAUDE.md プロダクト方針）と併せて守る。

## 要旨

12週カリキュラムの課金対象を「読み物（情報）」から「演習 + 自動検証 + 修了判定（判定）」に再定義する。情報はAIで無料再生産可能になり、単体では支払い理由がなくなったため。テキストは基盤素材であり、むしろ公開してよい。

## 診断（挟撃）

テキスト商品は上下から挟まれて売れない:

- **読める人**: 目次 + AI で同等の教材を無料で再現できる。情報としては支払い理由がない
- **読めない人**: 文章の量や密度をどうしても消費できない。供給量の問題ではなく消費形式の問題

## 原則: 再生産できるもの／できないもの

| 単位           | AI再生産 | 理由                                                                                                                            |
| -------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 情報（読み物） | ○        | 目次を渡せば誰でも作れる                                                                                                        |
| 採点（検証）   | ×        | 自分でAIに聞けるのは「自分が聞ける質問」だけ。気づいていない欠落は拾えない（盲点の非対称性）。固定課題 + 自動採点なら当てられる |
| 強制の足場     | ×        | 読めない層は「何を聞けばいいか」が分からず、自力でAI学習を運用できない。細分化 + 自動チェックの強制順序は自力で組めない構造     |
| 動く保証       | ×        | 単発生成の教材は壊れていることが多い。全ステップ実行検証済みの経路は時間の節約になる                                            |
| 修了記録       | ×        | 採点に実質があれば初めて信号価値が出る                                                                                          |

## 機関の差別化の核心

普通の人は1回の生成で「それっぽい文書」を出せる。しかし当社のシステムが行う多角的な分析・検証（正本からの組み立て、複数ゲートでの検査、実行検証、実画面確認）は、個人はできない・やらない。この差別化は商品そのものに同じ形で適用される: **カリキュラム自体が「検証済みであること」が商品の一部**であり、Week 0 でそれを読者に見せる。

## 商品設計

- SKU: 「12週の読み物」→「12週の演習 + 自動検証 + 修了判定」（29,800円 税込・価格方針不変）
- 課金対象: セッション末チェックポイント（自動採点）とモジュール末提出課題
- 採点は決定論的（テスト・構造化課題）から開始し、LLMレビュー・人間レビューは後で段階追加
- 目次全面公開は「教材の漏洩」ではなく「検証サービスの目録」になる。漏洩の懸念が消える

## Week 0（序文モジュール）

- 目的: お試し読者が購入前に価値を理解できること。説得ではなく構造の説明
- 位置: Phase 0 / weekNumber 0 / 常に無料（gating は week > 1 ため自動的に無料）
- 構成: ①このコースで手に入るもの（判定と保証） ②教材の作られ方（単発生成との違い）と進め方
- チェックポイント体験節は assessment 実装後に追加する
- 公開条件: 本番ブラウザでの全文自己レビュー後（他コンテンツと同じ手順）

## ロードマップ

| Phase | 内容                                                                            | 完了条件                             |
| ----- | ------------------------------------------------------------------------------- | ------------------------------------ |
| P0    | Week 0 序文を取込（非公開）→ レビュー後に公開フリップ                           | week-00 が本番で読める               |
| P1    | assessment MVP: チェックポイント機構（決定論的採点）。Week 0 体験 + W2-4 に装填 | 未購入でも W0 の体験課題が採点される |
| P2    | W2-12 publish フリップ（W2-4 にチェックポイントが載った後）+ 修了記録           | 購入者が判定付きで学べる             |
| P3    | モジュール末提出課題・レビュー（自動→人間段階追加）・修了証                     | 修了証に信号価値がある               |

**W2-12 のフリップは P1 完了まで行わない**（テキストだけで 29,800円は挟撃の真ん中で売ることになる）。

## 継続商品・アップセル（同じ方向）

上級モジュール、キャップストーンレビュー（人間/AI）、修了証、企業向けパック、姉妹サイト展開。すべて「判定・保証・記録」の単位で足す。情報追加型の継続商品は作らない。

## 守る規律

- AP規律: 未実装機能は「予定」と明示し、実装済みのように書かない
- 価格破壊禁止（相場よりやや安 + 品質）
- 教材は wiki/concepts 正本から組み立てる（推測で作らない）。Week 0 は教材でなく商品説明のため、記載は実システムの事実のみ
- コンテンツ公開前は本番ブラウザで全文自己レビュー
